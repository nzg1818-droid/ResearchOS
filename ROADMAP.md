# Roadmap

- Phase 1: real federated search, canonical library, lawful OA discovery, managed PDF import, persistent PDF annotations and source-linked material bank, Windows packaging.
- Gate: all 16 kickoff acceptance criteria must pass before Phase 1 can be declared complete.
- Phase 2 (blocked by gate): Zotero, structured extraction, electrocatalysis dashboard, semantic search.
- Phase 3/4: alerts, review workflows, advanced synthesis and updater.

No later-phase implementation is authorized by this delivery.
